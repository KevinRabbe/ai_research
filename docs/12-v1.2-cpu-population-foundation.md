## Implemented boundaries

### Strict canonical expressions

The repository now has a bounded parser for the canonical Boolean text format.

It rejects:

- malformed expressions;
- noncanonical child ordering;
- redundant or non-normalized expressions;
- trailing data;
- out-of-task variables;
- node, depth, and text-length overflow;
- reserved or punctuation-bearing variable names that would make serialization ambiguous.

The parser requires:

```text
parse(canonical_text(expression))
→ the exact normalized expression
```

### Immutable hypothesis packets

Each member packet binds:

- member identity;
- the complete public task, evidence, and interventions;
- complete candidate;
- canonical fragments;
- fragment roles;
- supporting and contradicting visible cases;
- visible predictions;
- confidence;
- counterexamples;
- uncertainties.

Canonical JSON and SHA-256 bind the complete packet. A strict decoder rejects:

- duplicate JSON keys;
- unknown or missing fields;
- altered evidence;
- noncanonical JSON;
- noncanonical expressions;
- invalid references;
- digest mismatches;
- oversized or non-ASCII payloads.

The decoder reconstructs the packet and task, validates them, reserializes them, and requires byte-for-byte identity.

### Semantic diversity and cooperative credit

Population metrics include:

- exact normalized truth-table distance;
- pairwise semantic error correlation;
- explicit undefined correlation for zero-variance error vectors;
- complete coalition evaluation;
- leave-one-source-out contribution;
- exact Shapley values.

For four members, every coalition is evaluated:

```text
2^4 = 16 coalitions
```

Tests distinguish additive, redundant, necessary, synergistic, and harmful members.

### Typed provenance graph

The graph has typed nodes for:

- evidence;
- intervention;
- fragment;
- complete candidate;
- counterexample;
- uncertainty.

It has typed edges for:

- support;
- contradiction;
- derivation;
- part-of relations;
- equivalence;
- repair;
- prediction.

Edges can contain several source nodes, permitting hyperedges for conclusions or interventions that require multiple premises.

Semantically equivalent expressions merge by exact truth-table identity. The merged node preserves:

- all canonical forms;
- all member identities;
- all packet hashes;
- all local fragment identifiers;
- all roles.

Graph construction is deterministic across packet order. Graph JSON and SHA-256 are canonical.

### Visible-only proof auditing

Every fragment claim is checked against public evidence.

The audit verifies:

```text
support claim
→ fragment agrees with observed output on that case

contradiction claim
→ fragment disagrees with observed output on that case

prediction claim
→ declared prediction equals the fragment's computed output

counterexample claim
→ complete candidate actually fails that visible case
```

A wrong complete candidate may remain useful when it carries truthful fragments or counterexamples. False proof metadata is marked unverified.

### Bounded symbolic synthesis

The deterministic synthesizer receives only public tasks and validated packets.

It can use:

- complete member candidates;
- fragments with verified metadata;
- operators present in accepted member proposals;
- recursively generated composites within fixed limits.

It cannot:

- access the hidden target;
- access hidden assignments;
- invent variables absent from member proposals;
- use operators available only in rejected fragments;
- enumerate an unrestricted grammar;
- exceed configured candidate, composition, node, depth, or evaluation limits.

It performs exact semantic deduplication without consulting target outputs. Ranking uses only visible-evidence agreement and deterministic simplicity.

The result records:

- semantic candidate identity;
- canonical and equivalent forms;
- visible mismatches;
- all source references;
- derivation rule and parent candidates;
- whether the semantics existed in any initial proposal;
- complete resource accounting and stop reason.

### Exact coalition synthesis attribution

The bounded synthesizer now runs once for every member subset. Each coalition fixes its selected candidate using visible evidence only. An external scorer is called only after selection.

This preserves the scientific firewall:

```text
visible task + member packets
→ bounded synthesis and fixed selected candidate
→ external score, including optional hidden exact evaluation
```

The external scorer cannot influence candidate generation, pruning, ranking, tie-breaking, or selection. Tests confirm that replacing the scorer with an inverted score leaves every selected coalition candidate unchanged.

The coalition report stores:

- selected semantic candidate for every subset;
- visible accuracy and synthesis trace;
- selected source-member provenance;
- novel-composition status;
- external score;
- leave-one-out score drop;
- exact Shapley value;
- whether member removal changes selected semantics;
- whether the member merely appears in provenance.

This separates several concepts that must not be conflated:

```text
member appears in provenance
≠ member is score-necessary
≠ member is semantically necessary
≠ member has positive average marginal value
```

A redundancy test confirms that two members may both appear as sources for the full result while either one can be removed without changing the selected semantics or score.

## Infrastructure synthesis proof

A deterministic unit case supplies:

```text
member M0: A and an accepted use of AND
member M1: B
visible target evidence: A AND B
```

No initial complete answer is `AND(A,B)`.

The bounded synthesizer constructs:

```text
AND(A,B)
```

The result is:

- consistent with all visible cases;
- semantically absent from every initial complete candidate;
- sourced from both members;
- reproducible across packet order;
- evaluated across all coalitions;
- necessary with respect to both members in the two-member test;
- attributed exactly through Shapley values.

This proves that the implemented machinery can express, detect, and attribute a novel multi-source composition. It does not prove that independently trained models will generate the necessary fragments at a useful rate.

## Scientific boundary

The current result supports this statement only:

> Given suitable structured contributions, the repository can validate, preserve, combine, attribute, and visibly verify them under deterministic resource bounds without allowing hidden evaluation to steer synthesis.

It does not yet support this statement:

> Different learned minds produce a reproducible capability gain over simpler controls.

That remains the Version 1 experimental gate.
