## Interpretation boundary

The result supports only the following narrow observations:

- the training/evaluation pipeline completed end to end;
- output parsing was essentially solved at all three scales;
- mean exact and mean semantic accuracy increased monotonically with model scale;
- the original 4M/10M/18M capacity range at the frozen 10M-token budget did not enter the predeclared capability band.

It does not establish that scale alone will solve the task, and it does not justify lowering the 20% threshold after observing the data.

## Predeclared recovery

The next protocol is frozen in `docs/20-v1-capability-band-recovery.md`. It changes model capacity only to PC-29M / PC-44M / PC-64M while retaining the original data, token budget, optimizer, seeds, greedy evaluation, and capability-band gate.

If the recovery selector also returns `all-too-weak`, that result must be preserved before another single-axis protocol revision is defined.
