## Fixed symbolic vocabulary

The implemented vocabulary contains exactly 75 tokens:

```text
22 structural, operator, Boolean, and control tokens
20 variable tokens: V0 through V19
33 bounded number tokens: N0 through N32
```

There is no unknown token. Unsupported tokens, variables, numbers, and token IDs fail closed.

## Public-task representation

The model receives only semantically relevant public information:

```text
variable order
visible assignments
visible outputs
intervention variable
intervention source and destination case indices
whether the intervention changed the output
```

Opaque task, evidence, and intervention identifiers are removed. Decoding creates stable local identifiers while preserving all model-visible semantics.

The codec independently verifies that every intervention references visible cases, changes exactly the declared assignment bit, and reports output change consistently.

## Mechanism grammar

Mechanisms use a bounded deterministic prefix grammar:

```text
TRUE
FALSE
V0 ... V19
NOT <expr>
AND <arity> <expr> ...
OR <arity> <expr> ...
ITE <condition> <when_true> <when_false>
```

The parser requires complete consumption and rejects truncation, trailing tokens, invalid arity, excessive depth or node count, and variables outside the current task. Valid expressions are normalized after parsing.

## Decoder-only training sequence

```text
<BOS>
<TASK> ... public evidence ...
<ANSWER> ... canonical mechanism ...
<EOS>
```

The explicit label mask scores only answer tokens and the final EOS. Prompt reconstruction is not part of the training objective.

## Context boundary

For `V` variables, `E` visible evidence cases, and `I` interventions:

\[
T_{task} = 9 + V + E(V + 3) + 8I
\]

At the initial evidence maximum:

```text
6 variables, 16 evidence cases, 3 interventions
→ 183 public-task tokens
→ sufficient room for a bounded answer inside 256 tokens

10 variables, 16 evidence cases, 3 interventions
→ 251 public-task tokens
→ insufficient room for most answers inside 256 tokens
```

Therefore the first learning preflight is fixed at six variables and a 256-token full causal sequence. Ten-variable tasks move to a later 384/512-token ablation.

## Exact decoder family

All three models share:

```text
decoder-only causal transformer
pre-normalization RMSNorm
bias-free projections
4x GELU feed-forward block
rotary positions
causal scaled-dot-product attention
tied input/output embeddings
head dimension 64
context 256
vocabulary 75
```

Exact parameter contracts:

```text
PC-4M:   4,741,120
PC-10M:  9,859,840
PC-18M: 17,731,584
```

Every constructor verifies its actual parameter count. Rotary and causal-mask buffers are precomputed, and the hot forward path avoids GPU-synchronizing token-value scans.

## CUDA runner qualification

The installed command is:

```text
plural-cognition-cuda-preflight
```

Its CPU-safe tests establish the ordered 30-case default sweep, strict CLI validation, JSON serializability, and list-only operation without CUDA.

The real mode refuses to run when CUDA is unavailable. On the target machine it measures real mixed-precision forward, backward, and AdamW steps, records hardware/software metadata, stops larger batches after OOM or exceeding 13.5GB allocated VRAM, and writes an atomic JSON report.

See `docs/10-v1.1-cuda-preflight.md` for the exact PowerShell procedure.
